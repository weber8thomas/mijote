# Mijoté

Planificateur de repas familial de saison, partageable avec un bébé de 11 mois.
PWA mobile-first (téléphone, tablette, ordinateur).

**Vitrine en ligne** : https://weber8thomas.github.io/mijote/ — prototype 100 % statique, les données restent dans le navigateur.

## Ce que fait la vitrine
- **Semaine** : 14 repas (déjeuner et dîner) + un dessert par jour. Pour chaque repas, 6 idées de saison en grille 2 × 3 : tu choisis, repas par repas, et les suggestions suivantes s'ajustent (poisson 2×, légumineuses, fer chaque jour, viande rouge ≤ 2, cuissons longues le week-end, restes du dîner pour le midi). Appui long : aperçu.
- **Courses** : liste agrégée Marché / Supermarché par rayon, total estimé, « j'ai déjà », placard, partage, impression. Cochée en direct entre deux onglets.
- **Recettes** : 47 recettes de saison (déjeuners, dîners, desserts), toutes vérifiées par le linter bébé ; favoris, écarter, nouveautés (IA simulée), ajout de ta recette.
- **Aujourd'hui** : repas du jour, tâches « ce soir, pour demain », fer du jour, produits de saison.
- **Impression** : tableau frigo A4 paysage et liste de courses.
- Installable (Android et iPhone) et utilisable hors ligne.
